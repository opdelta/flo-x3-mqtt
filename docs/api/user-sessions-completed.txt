Synthetic example. Identifiers and values are not from a real account.

GET https://emobility.flo.ca/v3.1/user/sessions
Authorization: Bearer <access-token>

Example completed-session entry, when FLO returns one:

[
  {
    "id": "test-completed-session",
    "station": {
      "id": "test-station-id"
    },
    "sessionState": "Completed",
    "amperage": 0,
    "amperageOffer": 0,
    "voltage": 0,
    "energyTransferredWh": 12345,
    "cost": {
      "estimatedCost": 1.25,
      "currency": "CAD"
    }
  }
]

The bridge uses the returned final energy/cost values without calculating a
tariff. If no session is returned while idle, it retains the last received
totals. Missing measurements in a returned session remain unknown.

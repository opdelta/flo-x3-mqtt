Synthetic example. Identifiers and values are not from a real account.

PUT https://emobility.flo.ca/v3.1/homestation/test-uid/configuration
Authorization: Bearer <access-token>
Content-Type: application/json

{
  "restrictedAccess": {
    "version": "1.0.0",
    "value": true
  },
  "timezone": {
    "version": "1.0.0",
    "value": "UTC"
  }
}

The bridge copies stationPreferences.configurations from GET /v3.1/homestation
and changes only restrictedAccess.value. Other settings and version wrappers
must be preserved; do not replace a real configuration with this sample.

The PUT response body is not used. The bridge reads stations and sessions again
to publish the confirmed state. Restricted access is not a stop command.

Synthetic example. Identifiers and values are not from a real account.

POST https://emobility.flo.ca/v3.1/homestation/chargingstation/test-uid/session/start
Authorization: Bearer <access-token>
Content-Type: application/json

{
  "evseId": "1"
}

test-uid represents chargingStationUid, not chargingStationId.
evseId comes from the current station's evse.id.

The bridge first fetches /v3.1/homestation and requires an online charger,
a reported connected vehicle, and RemoteStartStop capability. Rejected
commands do not send a POST. Stations and sessions are read back afterward.

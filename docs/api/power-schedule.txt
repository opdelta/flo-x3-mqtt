The bridge obtains the native schedule from GET /v3.1/homestation.
ON/OFF commands copy that document and change only isEnabled. JSON commands
replace the full schedule and must preserve FLO's actual season/period schema.
This empty manual example does not define any charging windows.

The PUT response body is not used. Stations and sessions are read back
immediately. The Home Assistant weekly Schedule-helper blueprint is separate
from this charger-native schedule.
